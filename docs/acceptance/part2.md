# Чекліст приймання — частина 2 (AI-аналітик)

Кожен пункт співставлено з розділом «AI-аналітик» специфікації. Ручні процедури
виконуються на paper-ключах Alpaca; перед початком обовʼязково `pnpm check`.
Пункти позначаються `[x]` лише після виконання відповідної процедури.

## 1. Автоматична перевірка

- Команда: `pnpm check`.
- Очікується: PASS (fmt, білд веба, lint, тести Rust + Angular, згенеровані
  типи не змінені).
- Статус: PASS (2026-11-11).

## 2. Налаштування AI

- Кроки: «Налаштування» → розділ «AI-аналітик» → «Зберегти».
- Очікується: перемикач, модель, рівень мислення (низький/середній/високий),
  бари контексту, максимум пропозицій, глибина днів, частка стратегії AI у %
  зберігаються; частка вводиться у відсотках (25 → 0.25 у конфігу).
  Некоректні значення бекенд відхиляє повідомленням українською
  (bars 20..=250, пропозицій 1..=20, днів 1..=30, частка (0, 1]).
- Статус: [ ]

## 3. Ручний запуск аналізу

- Кроки:
  1. Увімкнути AI-аналітик, переконатися, що ключ `anthropic_api_key` збережено
     («Налаштування» → ключі → «Перевірити»).
  2. «AI-аналіз» → «Запустити аналіз».
  3. Одразу натиснути кнопку ще раз (під час виконання першого).
- Очікується: перший запуск повертає повідомлення «запущено у фоні» з датою
  аналізу; повторний — помилку 409 «уже виконується»; після завершення таблиця
  оновлюється живо (події журналу), у зведенні — кількість пропозицій і витрати
  LLM (токени, $).
- Статус: [ ]

## 4. Пропозиція → схвалення → ордер (paper)

- Кроки:
  1. Дочекатися пропозиції зі статусом «намір створено» у «AI-аналізі»
     (пропозиція пройшла ризик-менеджер).
  2. «Схвалення» → схвалити намір, створений з AI-пропозиції.
  3. Перевірити ордер у панелі Alpaca paper.
- Очікується: намір потрапляє у звичайний конвеєр (статус «pending_approval»);
  після схвалення ордер відправлено з коректним `client_order_id`; у журналі
  події `ai_proposal` (з поясненням, токенами, вартістю) → `intent` → `order`.
  Пропозиція, відхилена ризиком, має статус «відхилено ризиком» із причиною
  і наміру не створює.
- Статус: [ ]

## 5. Бюджет LLM спільний із новинним фільтром

- Кроки: виставити `daily_budget_usd` = 0.01 у «Фільтрах», запустити аналіз.
- Очікується: при вичерпанні бюджету AI-пропозиції за день не створюються;
  в журналі подія про вичерпання бюджету; витрати AI видно в зведенні
  «AI-аналізу».
- Статус: [ ]

## 6. AI не бере участі в бек-тесті

- Кроки: запустити бектест при увімкненому AI-аналітику.
- Очікується: бектест працює як у частині 1; жодних звернень до Claude,
  журнал бектесту не містить AI-подій.
- Статус: [ ]

## Пакування

- Команда: `pnpm package`.
- Очікується: `target/release/bundle/nsis/Fond_0.1.0_x64-setup.exe`;
  після встановлення розділ «AI-аналітик» у «Налаштуваннях» і екран
  «AI-аналіз» у навігації.
- Статус: [ ]
